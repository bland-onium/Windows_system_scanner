### Способ развёртывания:
Качаем файл PSCheckerSF.bat или PSCheckerSFsss.bat и запускаем на интересующем нас ПК

#### PSCheckerSF.bat - версия, выводящая всё в файл. При запуске спрашивает насколько полный отчёт нужен
#### PSCheckerSFsss.bat - "Тихая" версия, обрабатывает всё незаметно и автоматизированно
Права администратора не нужны
Совместима с Windows 7 и новее

Текущий список сканирования:
MS Windows
MS Office
BIOS
CPU (Процессор)
GPU (VRAM, Видеокарта)
RAM (ОЗУ, Оперативка)
Disks
Network Adapter
Network Settings
Monitors
Peripherals (including USB Flashes)
List of installed programs (Now it scans all programs, connected to registry | Пока что сканирует всё, что подвязано к реестру. В дальнейшем планируется введение более широкого функционала с привлечением системных вызовов на ЯП низкого уровня)

### Новости обновлений
6-я вервия получила тоже не много обновлений, но обновления весомые:
- Теперь программа работает в реальном многопотоке (сколько ядер имеет процессор - столько потоков берёт код)
- Больше стабильности + исправление ошибок
- При работе показывает, какие задачи были выполнены и за какое время
- Точнее работает с Мониторами и Периферией
- Убран MAS, т.к. он тяжёлый
- Т.к. MAS убран, версия с возможностью его запускать лежит в папке old_ver

5-я версия получила не так много обновлений, но улучшила функциональность:
- Сканер-Активатор MS и Office работает стабильнее и надёжнее
- MAS теперь запускается локально и не обращается к серверу (Антивирус всё равно надо выключать)
- Появилась функция сканирования мониторов
- Появилась функция сканирования периферии
- Появилась функция поиска ViPNeT
- Появилась функция оптимизации системы (Убирает телеметрию, отключает ненужные службы, отключает поиск, сильно притормаживает MS Edge)

4-я версия приобрела ещё одно ведрышко апдейтов, конкретно:
- Теперь есть выбор вывода сканирования девайсов
- Появилось сканирование сетевого адаптера и сетевых настроек
- Сканер программ сканирует только в одном режиме и ищет все программы на пк
- Добавлена функция оптимизации системы, которая выключает часть беполезных/неэффективных функций, а также отключает Windows Defender
- Сделан механизм автоматического закрывания программы
- (надеюсь, что это правда) Исправлена ошибка записи лога на другую флешку. Теперь всё должно записываться на ту флешку, с которой программа была запущена
