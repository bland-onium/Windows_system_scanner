# WINDOWS SCANNER & OPTIMIZER

This script made for automatical scanning system components, seeking for licenses, adding more optimisation in system and 
Программа создана для автоматизированного сканирования системных компоненов, обнаруживания лицензий и всей необходимой информации.

### Способ развёртывания:
Качаем файлы PSChecker.ps1 и PSChecker.bat, кладём их в одну папку и запускаем .bat файл от имени администратора
Программа спросит - хотим ли мы устанавливать лицензии на Винду и Офис, после реакции пользователя просканирует всё, что должна сканировать

Текущий список сканирования:
MS Windows
MS Office
BIOS
CPU (Процессор)
GPU (VRAM, Видеокарта)
RAM (ОЗУ, Оперативка)
Disks
Network Adapter
Network Settings
List of installed programs (Now it scans all programs, connected to registry | Пока что сканирует всё, что подвязано к реестру. В дальнейшем планируется введение более широкого функционала с привлечением системных вызовов на ЯП низкого уровня)

### Новости обновлений
4-я версия приобрела ещё одно ведрышко апдейтов, конкретно:
- Теперь есть выбор вывода сканирования девайсов
- Появилось сканирование сетевого адаптера и сетевых настроек
- Сканер программ сканирует только в одном режиме и ищет все программы на пк
- Добавлена функция оптимизации системы, которая выключает часть беполезных/неэффективных функций, а также отключает Windows Defender
- Сделан механизм автоматического закрывания программы
- (надеюсь, что это правда) Исправлена ошибка записи лога на другую флешку. Теперь всё должно записываться на ту флешку, с которой программа была запущена
